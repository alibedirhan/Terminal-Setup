# Güvenlik

Terminal Setup kullanıcı shell ayarlarını, terminal renklerini ve bazı CLI araçlarını değiştirebilir. Bu yüzden güvenlik açısından açık ve kontrollü ilerlemek önemlidir.

## Desteklenen kullanım

- Ubuntu 20.04 ve üzeri
- Normal kullanıcı hesabı
- Root olarak çalıştırmama

## Güvenlik ilkeleri

- Script root olarak çalıştırılmamalıdır.
- İşlem öncesi yedek alınmalıdır.
- Harici scriptler mümkün olduğunca geçici dosyaya indirilip ayrı çalıştırılmalıdır.
- Kişisel dosyalar repoya eklenmemelidir.

## Sorun bildirimi

Güvenlik problemi bulursanız GitHub Issues yerine mümkünse doğrudan repo sahibiyle iletişim kurun. Genel hatalar için Issues kullanılabilir.
